# 安全政策

[English](../SECURITY.md)

YM_Link 目前是开发预览，安全问题按当前 `main` 的实现跟踪。请注明提交号、操作系统、影响和使用合成数据的最小复现；暂不提供稳定版本支持周期或响应时限承诺。

请通过 GitHub 的[私下漏洞报告入口](https://github.com/forrestzhu/youmu-link/security/advisories/new)报告安全问题。修复前不要在公开 issue 中披露漏洞细节，也不要上传私钥、令牌、配对码、身份 / 信任存储、用户文件路径或原始日志与媒体。只提供脱敏信息。普通功能问题可以提交到 [Issues](https://github.com/forrestzhu/youmu-link/issues)。
