## 依赖与风险

- M2 起需要第二台真实设备（Windows 电脑或头显测试桩）；头显侧 M5 前用桌面测试桩模拟游目端。
- 屏幕采集与硬件编码在两平台的 API 差异是 M4 最大风险，M2 期间先做采集可行性 spike。
- 游目端集成节奏以游目仓库任务为准，本仓库协议版本不超前实现未定稿字段。

## 未立项候选

- 镜像画面裁剪 / 缩放布局、多显示器同屏。
- 电脑端“投到这里”反向发起（头显浏览时主动唤醒桌面端）。
- 传输限速与队列管理 UI 精细化。
