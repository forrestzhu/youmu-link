# YM_Link 产品定义

状态：v0.1 草案（2026-10-27，随 [YML-001](../tasks/archive/YML-001-bootstrap.md) 建立）。本文是 YM_Link 的产品事实来源；与游目主产品的关系见游目仓库 PRODUCT。

## 定位

YM_Link 是游目的桌面伴侣：一台 Windows / macOS 电脑 + 一台 Meta Quest 3 / 3S，同一局域网内互联。它不改变游目“本地视频私人影院”的核心定位，只解决两件事：**电脑上的内容进头显**（屏幕镜像）和**电脑上的影片免拷贝播放**（文件浏览 / 流式播放 / 传输）。

目标用户即游目用户：私人观影优先，画质与舒适优先，不追求远程桌面级生产力。

## 用户与场景

- 半躺在头显里，想看电脑上正在播放 / 显示的任何内容（网页视频、本地播放器、桌面）→ 镜像整块所选屏幕到游目大屏。
- 影片存在电脑 / 移动硬盘上，不想每次拷贝到头显 → 在游目内浏览电脑目录直接播放，或把常看的传输到头显本地。
- 用户不理解的 网络 / IP / 防火墙 不应成为使用门槛：双端打开即互相发现，配对只需确认一个短码。

## 功能

| # | 功能 | 内容 | 阶段 |
| --- | --- | --- | --- |
| F0 | 设备发现与配对 | 双端同网段自动互相发现；首次连接经六位短码显式配对；信任持久化，公钥变化拒绝；断线自动重连。 | M2 |
| F1 | 屏幕镜像 | 桌面端选择任一显示器整屏镜像；头显端在游目大屏播放，含系统音频（可关）；暂停 / 停止 / 切换屏幕由任一端发起。 | M4 |
| F2 | 文件浏览与播放 / 传输 | 头显端浏览电脑授权目录；视频可流式播放（seek / 字幕外挂优先）或传输到头显本地；传输可暂停 / 取消 / 断点续传。 | M3 |

头显侧入口：游目内的 YM_Link 面板（发现列表、配对、已配对设备、电脑屏幕、电脑文件、传输任务）。桌面侧入口：主窗口（设备列表 + 屏幕选择 + 共享目录管理 + 传输状态）。

## 非目标

- 不做头显对电脑的键鼠反向控制（镜像只单向 + 可选音频）。
- 不做公网穿透 / 中继、多房间同步、剪贴板同步。
- 不做转码服务：流式播放直接 Remux / 原样传输，解码能力按 Quest 实测，超出能力引导用户传输或换源。
- 初期不做多对多：一台电脑可配对多台头显，但同一时刻单头显连接。

## 体验与安全原则

1. **零配置优先**：安装即用，无账号、无云端注册；发现不到设备时给逐步排查提示而非错误码。
2. **显式信任**：首次连接必须短码确认；配对关系可随时在任一端删除；发现报文零身份信息（见 [PROTOCOL](../engineering/PROTOCOL.md)）。
3. **隐私**：文件路径、目录结构只在配对设备间加密传输；不记录播放历史到电脑端；崩溃日志不含路径明文。
4. **舒适**：镜像默认适配游目大屏比例与距离，帧率 / 延迟档位可调，弱网先降分辨率不冻结 UI。
5. **互通边界诚实**：编解码 / 延迟指标按真实硬件实测标注，不承诺“零延迟”。

## 分发

- 当前开发包：GitHub Actions 成功 main 构建上传 Windows x64 ZIP 与 macOS arm64 ZIP，附校验和与完整许可。正式 Windows 安装器、macOS 通用 dmg / 签名 / 公证及发行渠道另行确定；Meta 商店不涉及。
- 版本号策略随 M6 分发任务确定（对齐游目 `yyyyMMdd.HHmm` 显示版本惯例）。
- 许可证：原创代码采用 Apache-2.0；依赖保留各自许可。GitHub 仓库当前仍 private，历史邮箱已按用户授权修正；历史路径 / 内部说明清理与公开时点仍由用户决定，同步更新 [AGENTS](../../AGENTS.md)。GitLab 迁移不再作为当前开源前置条件。

## 验收口径

- 每项功能以真实双设备（电脑 + 头显）验收为准；loopback / 单机测试只能证明协议逻辑，不能标记互联通过。
- 镜像体验指标（延迟、帧率、音画同步）在 M4 定基准并写入 TESTING；在此之前不预填数字。
