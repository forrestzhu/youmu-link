# Security policy

[简体中文](docs/SECURITY.zh-CN.md)

YM_Link is a development preview. Security reports are tracked against current `main`; there is no stable-version support schedule or guaranteed response time. Include the commit, operating system, impact and a minimal reproduction using synthetic data.

Use GitHub's [private vulnerability reporting](https://github.com/forrestzhu/youmu-link/security/advisories/new). Keep vulnerability details private until fixed. Do not attach private keys, tokens, pairing codes, identity or trust stores, user file paths, raw logs or media; provide redacted information. Report ordinary bugs through [Issues](https://github.com/forrestzhu/youmu-link/issues).
