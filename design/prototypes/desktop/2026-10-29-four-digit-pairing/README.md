## 打开与体验

直接打开 `index.html`，或在仓库根目录运行：

```sh
python3 -m http.server 8768 --bind 127.0.0.1 --directory design/prototypes/desktop/2026-10-29-four-digit-pairing
```

浏览器访问 `http://127.0.0.1:8768/`。没有第三方资源、真实设备发现、网络配对或数据持久化；设备名称和 192.0.2.* 地址均为合成示例。

这是当前Mac上的本地预览，服务退出后链接会失效。Codex内置浏览器应使用上面的HTTP入口；当前本机另有单文件离线副本 `artifacts/yml008/ym-link-pairing-offline.html`（CSS /JS均已内联，可保存备用；内置浏览器不接受file协议）。原始三文件保留在本目录。

## 本次拟定交互

- 保持 YM_Link 独立品牌入口与链接图标。连接、四格数字与数字键盘在同一头显面板完成。
- 电脑显示四位数字，头显使用大按键输入；支持前导零、删除和取消。第四位输入后立即自动配对，禁用数字 /删除以免重复提交，取消仍可用。
- 四格与数字键盘共用最大280px宽度、左右外沿对齐；单格目标52px，间隔弹性分配且最小12px，窄处可收缩。左侧集中显示操作说明与电脑名称。柔和的实体按键保留大命中区，取消在键盘左下角；提交前后不改变键盘位置。界面不常驻解释自动配对机制，真实进度由顶部状态显示。
- 错码在原位轻晃四格并显示错误，随后自动清空，可直接重新输入；错误提示到下一次输入才收起。电脑码及本窗口的五分钟截止保持，重试不续期。真实过期 /限速另行反馈；取消不应被迟到回调覆盖。减少动态效果时保留文字和状态色。
- 配对成功后保留信任；断开、取消重连和返回列表都不删除信任。再次连接免输码。
- 电脑侧同一头显的端口更新只替换当前地址，设备数保持一台。混合版本给更新提示。

顶部控件仅用于讨论：选择状态可直接查看错误、过期、限速、断线和版本提示，也会重置该演示情景；“窄面板”查看纵向排布；“模拟端口变化”验证一台设备；“重新演示”从发现页开始。新逻辑配对窗口的示例码按 `2568 → 0427 → 6810 → 3094` 循环，原位重输沿用本窗口的码 /截止；每次准备新尝试仍计入一分钟五次门禁。真实码生成、重试会话、协议兼容与限速必须在定稿后的双端实现另验。

## 讨论 / 验证清单

1. 看品牌入口与同面板输入布局；点三位，应仍等待输入，可以删除；第四位后应立即自动配对。
2. 默认输入 `2568`，无需额外点击即可进入已连接；回列表后连接保持。
3. 重新加载默认稿，输入错误码 `0000`：四格轻晃 /显示不正确后清空，仍在当前面板；直接输入 `2568` 可成功。选择新的四位配对情景可测试 `0427` 等前导零。
4. 第四位输入后或错误反馈期间点左下角取消，旧回调不应恢复连接或清除下一次的新输入；取消握手后仍可重新连接。
5. 选择过期、频繁尝试与另一端需要更新，检查文案与可用操作；限速中返回列表再连接仍受限制。
6. 已连接后断开，再连接免输码；取消一次重连也不应忘记设备。
7. 连续点击端口变化，电脑列表始终一台。切换中英文与窄面板查看文字、码位和按键。
