# YM_Link demo 原型（2026-10-27）

浏览器直接打开 `index.html`（无构建、无依赖、无网络请求）。设计依据与状态机见 [demo 设计](../../../../docs/plans/2026-10-27-demo-design.md)。

## 覆盖的交互流

- **发现**：两侧初始“搜索中”→ 约 1.6 秒后互相出现在对方设备列表（演示控制可重扫；已发现 / 断线时主区显示对应提示而非搜索动画）。
- **配对**：任一侧点“连接”→ 桌面端窗口内弹窗显示六位码（5 分钟倒计时，仅覆盖桌面窗口，视图切换不受阻），头显端输入同一码完成配对；输错码或未输满六位会在头显端显示错误提示并保留已输入内容；配对码过期两侧均有明确提示（演示控制可模拟过期）；取消后回到已发现。
- **连接后（桌面端）**：屏幕镜像标签（显示器选择 / 音频 / 画质 / 开始-停止，状态条显示模拟 fps / 码率 / 延迟）；文件共享标签（授权目录管理占位）。
- **连接后（头显端）**：电脑屏幕入口（等待电脑开始镜像）；电脑文件（面包屑目录 / 直接播放 / 传输到本机）；传输任务进度；“直接播放”进入流式播放态。
- **断线重连**：演示控制模拟断开（仅连接后生效），两侧显示“正在重连”提示（含播放页与传输页），2.4 秒后自动恢复；断线期间文件操作禁用，传输暂停并在恢复后自动继续。

## 明确不承诺

- 原型不连接真实网络，进度 / 码率 / 延迟均为模拟数值。
- 不是视觉合同：间距、配色、图标可在实现期调整；约束的是页面结构、状态名与转移。
- 配对码方向（桌面显示 / 头显输入）是 M1 评审关注点之一。
- 键盘可访问性是已知限制：显示器卡片、目录行以点击为主，弹窗无 Esc / 焦点圈；按 M1 评审结论决定是否补齐。

## 评审修订记录

- 2026-10-27 第 1 轮 CR 后：配对弹窗从全屏遮罩改为桌面窗口内遮罩（视图切换可达）；重扫 / 重置不再终止演示计时；断线时播放页不再残留 "null" 标题、传输 / 文件页显示断线提示并在恢复后自动继续；配对错误与过期在头显端可见；状态命名映射写入设计文档。
- 2026-10-27 第 2 轮 CR 后：头显主页不再残留上一屏控制按钮；断线窗口内手动重新配对后传输同样自动继续；断线文案不再对镜像“自动继续”过度承诺；“字幕包”返回上级回到其父级“电影”；配对输入草稿做属性转义；设计文档桌面文件标签描述与原型对齐。

## 已知限制（不修复，实现期处理）

- 镜像 fps 恒为 72 不抖动、“暂停”chip 与“传输中”同色，属模拟保真度小项。
- 面包屑只显示“共享目录 / 当前目录名”两级，深层目录导航靠返回上级。
