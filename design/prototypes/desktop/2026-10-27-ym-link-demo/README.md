# YM_Link demo 原型（2026-10-27）

浏览器直接打开 `index.html`（无构建、无依赖、无网络请求）。设计依据与状态机命名见 [demo 设计](../../../../docs/plans/2026-10-27-demo-design.md)。

## 覆盖的交互流

- **发现**：两侧初始“搜索中”→ 约 2 秒后互相出现在对方设备列表（演示控制可重扫）。
- **配对**：任一侧点“连接”→ 桌面端弹窗显示六位码（5 分钟倒计时），头显端输入同一码完成配对；演示控制可模拟码过期。
- **连接后（桌面端）**：屏幕镜像标签（显示器选择 / 音频 / 画质 / 开始-停止，状态条显示模拟码率延迟）；文件共享标签（授权目录管理占位）。
- **连接后（头显端）**：电脑屏幕入口（等待电脑开始镜像）；电脑文件（面包屑目录 / 直接播放 / 传输到本机）；传输任务进度；“直接播放”进入流式播放态。
- **断线重连**：演示控制模拟断开，两侧显示“正在重连”，2.4 秒后自动恢复，传输暂停状态保留。

## 明确不承诺

- 原型不连接真实网络，进度 / 码率 / 延迟均为模拟数值。
- 不是视觉合同：间距、配色、图标可在实现期调整；约束的是页面结构、状态名与转移。
- 配对码方向（桌面显示 / 头显输入）是 M1 评审关注点之一。
